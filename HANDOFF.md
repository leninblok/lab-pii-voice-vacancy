# Передача проекта

Актуальная версия — 11 ноября 2026 года.

## Что это

«Вакансия голосом» помогает собрать описание вакансии из свободного рассказа. В центре всегда остаётся редактируемый документ, а ИИ распознаёт речь, приводит сведения к структуре и подсказывает один следующий вопрос.

## Как запустить

1. `npm ci`
2. Скопировать `.env.example` в `.env.local` и добавить серверный `OPENAI_API_KEY`
3. `npm run dev`

Для проверки: `npm test`, `npm run typecheck`, `npm run build`.

## Как устроено

- `src/app/page.tsx` — основной сценарий, локальное хранение вакансий, запись, экспорт и история изменений
- `src/app/api/transcribe/route.ts` — серверное распознавание через Whisper
- `src/app/api/update/route.ts` — серверное обновление документа и вопроса
- `src/lib/prompt.ts` — правила для агента
- `src/lib/vacancy.ts` — модель документа, оценки тем, валидация и типографика
- `src/lib/pdf.ts` — печать PDF из тех же классов и стилей, что у редактора
- `src/components/VacancyEditor.tsx` — единая редактируемая поверхность и анимация изменённых фрагментов

Вакансии и история изменений хранятся в `localStorage` браузера. Аудио и расшифровки не сохраняются после успешной обработки.

## Ограничения

Ключ OpenAI не попадает в клиент и репозиторий. Для Vercel нужно задать `OPENAI_API_KEY` в Environment Variables и переразвернуть проект. Агент пока требует дальнейшей настройки: он не всегда достаточно точно отделяет факт от догадки и выбирает лучшее уточнение.

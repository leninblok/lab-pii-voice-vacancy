## Запуск

Нужны Node.js 22, npm и ключ OpenAI API с доступом к Whisper и текстовой модели.

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env.local` и укажите `OPENAI_API_KEY`. Файл `.env.local` исключён из Git. Не вставляйте ключ в код или клиентские переменные окружения.
3. Запустите `npm run dev` и откройте `http://localhost:3000`.

По умолчанию для текста используется `gpt-4o-mini`; при необходимости выберите доступную модель через серверную переменную `OPENAI_TEXT_MODEL`. Распознавание использует `whisper-1`.

Проверки: `npm test`, `npm run typecheck`, `npm run build`. Production-сервер после сборки запускается командой `npm run start`. Для проверки четырёх редакторских случаев запустите приложение на порту 3100 и выполните `node tests/integration/editorial-eval.mjs`; эта проверка обращается к OpenAI и расходует API.

## Размещение на Vercel

Импортируйте публичный репозиторий в Vercel как проект Next.js. В настройках проекта задайте серверную переменную `OPENAI_API_KEY` и при необходимости `OPENAI_TEXT_MODEL`. После публикации откройте HTTPS-адрес и проверьте микрофон, оценку ответа и генерацию. Для двух последовательных вызовов модели в маршруте обновления настроен максимальный срок выполнения 120 секунд; доступность этого лимита зависит от настроек и тарифа Vercel. Ключи не помещаются в репозиторий.

Лимит обращений в коде действует только в пределах одного работающего экземпляра и является защитой для демонстрации. Для общедоступного многопользовательского сервиса нужны централизованное ограничение запросов и контроль расходов на стороне инфраструктуры.

Документы вакансий и история изменений хранятся локально в браузере. Запись и её распознавание постоянно не сохраняются; неудачная попытка доступна только в текущей сессии. Тексты и аудио обрабатываются OpenAI для предоставления функции; условия обработки необходимо определить до использования реальных данных.

## Текущие ограничения

Автоматизированный браузер в рабочей среде недоступен: полная проверка интерфейса, мобильного экрана, работы с буфером обмена и обработки всех ошибок остаётся ручной. Пользователь подтвердил исправление конкретной смысловой ошибки при записи; конечный набор тестов не гарантирует, что модель всегда сохранит смысл или оценит темы правильно. Типографическая нормализация пока охватывает только безопасную часть правил; полная редакторская приёмка и проверка сложных переносов PDF продолжаются.

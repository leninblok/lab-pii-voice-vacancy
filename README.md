## Запуск

Нужны Node.js 22, npm и ключ OpenAI API с доступом к Whisper и текстовой модели.

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env.local` и укажите `OPENAI_API_KEY`. Файл `.env.local` исключён из Git. Не вставляйте ключ в код или клиентские переменные окружения.
3. Запустите `npm run dev` и откройте `http://localhost:3000`.

По умолчанию для текста используется `gpt-4o-mini`; при необходимости выберите доступную модель через серверную переменную `OPENAI_TEXT_MODEL`. Распознавание использует `whisper-1`.

Проверки: `npm test`, `npm run typecheck`, `npm run build`. Production-сервер после сборки запускается командой `npm run start`.

## Размещение на Vercel

Импортируйте публичный репозиторий в Vercel как проект Next.js. В настройках проекта задайте серверную переменную `OPENAI_API_KEY` и при необходимости `OPENAI_TEXT_MODEL`. После публикации откройте HTTPS-адрес и проверьте микрофон, оценку ответа и генерацию. Ключи не помещаются в репозиторий.

Лимит обращений в коде действует только в пределах одного работающего экземпляра и является защитой для демонстрации. Для общедоступного многопользовательского сервиса нужны централизованное ограничение запросов и контроль расходов на стороне инфраструктуры.

В текущей версии ответы находятся в памяти страницы и теряются при перезагрузке. Пользователь может скопировать или скачать готовый текст. Тексты и аудио обрабатываются OpenAI для предоставления функции; условия обработки необходимо определить до использования реальных данных.

# Материалы к сдаче

Состояние: переработанная локальная версия проходит технические проверки; публикацию и ручную приёмку нужно подтвердить перед отправкой.

- Репозиторий: https://github.com/leninblok/lab-pii-voice-vacancy — актуальность содержимого нужно проверить после синхронизации.
- Публичный адрес: пока не подтверждён; требуется авторизация в Vercel и проверка опубликованного приложения.
- [Спецификация](../SPEC.md), [продуктовые принципы](../PRODUCT_PRINCIPLES.md), [редакторские правила](../EDITORIAL_GUIDELINES.md).
- [Решения редизайна](../docs/REDESIGN_DECISIONS.md), [история проекта](../docs/PROJECT_HISTORY.md), [QA](../docs/QA.md) и [инструкция](USER_GUIDE.md).

Исходное задание использует слово «резюме» для итогового структурированного текста. В контексте интервью результат продукта трактуется как описание вакансии для будущего сотрудника, а не резюме кандидата.

Пользователь определял задачу, продуктовые принципы и редакторские ориентиры. ИИ помогал исследовать материалы, составлять документацию, писать и проверять код. Процент участия по времени не измерялся. Проверки реального микрофона, мобильной вёрстки и устойчивости генерации по всему корпусу необходимо подтвердить отдельно; нельзя выдавать автоматические тесты за такую приёмку.

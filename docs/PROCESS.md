# Как выполняется работа

Этот журнал ведётся по фактическим действиям. Он нужен для объяснения процесса в тестовом задании; процент участия ИИ не вычисляется до завершения работы и не выдаётся за измеренный без методики.

| Шаг | Что сделано | Роль пользователя | Роль AI-ассистента |
|---|---|---|---|
| Исследование | Изучены задание, конспекты, состав артефактов; создан план и обзор источников | Поставил задачу, предоставил материалы | Прочитал материалы, выделил требования и подготовил документы |
| Продуктовая рамка | Описаны пользователь, сценарий, границы, пример и критерии; зафиксированы решения | Согласовал план, подтвердил результат и сообщил срок | Подготовил идею, вопросы и журнал решений |
| Выбор интеграций | Определены OpenAI/Whisper, GitHub и Vercel | Выбрал поставщиков и подготовил локальный ключ | Проверил официальную документацию и спроектировал использование |
| Спецификация и разработка | Подготовлена спецификация, инструкции агенту и первая версия кода | Уточняет доступы и проверяет продукт | Описал состояния, API, интерфейс и реализацию |
| Проверка и сдача | В процессе | Проверяет итог, при необходимости помогает с доступами | Должен выполнить проверки, исправить проблемы и подготовить материалы |

Применяемые подходы: Spec-First, последовательная реализация одного пользовательского пути, явное разделение допущений и подтверждённых фактов, проверка результата в браузере. Для формулировок использованы рабочие файлы `PLAN.md`, `PROJECT_IDEA.md`, `SPEC.md` и инструкции `AGENTS.md`; системные промпты для оценки и генерации находятся в соответствующих серверных обработчиках.

Оценка присутствия ИИ по текущему журналу: **5 из 5 этапов (100% этапов)** выполнялись с участием AI-ассистента. Это доля этапов с использованием ИИ, а не процент затраченного времени или кода, написанного без участия человека. Пользователь определил направление и условия работы, выбрал интеграции, подготовил доступ и проверяет результат; реальные вызовы API и локальные проверки выполнялись средствами разработки.

После публикации добавить подтверждённые ссылки на репозиторий и прототип, а также результаты проверки браузерного сценария.

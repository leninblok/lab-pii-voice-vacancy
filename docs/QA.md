# Проверка продукта

Этот журнал содержит только актуальные результаты для текущей версии. Требования описаны в [продуктовых принципах](../PRODUCT_PRINCIPLES.md), [спецификации](../SPEC.md) и [редакторских правилах](../EDITORIAL_GUIDELINES.md); принятые ограничения — в [решениях редизайна](REDESIGN_DECISIONS.md).

## Автоматические проверки

| Проверка | Что подтверждает | Статус |
| --- | --- | --- |
| `npm test` | Модель вакансии, сохранение фактов, демонстрационную вакансию и экспорт | Пройдено: 13/13 |
| `npm run typecheck` | Корректность TypeScript | Пройдено |
| `npm run build` | Production-сборку Next.js, favicon и два действующих серверных маршрута | Пройдено |
| `git diff --check` | Отсутствие ошибок пробелов в изменениях | Пройдено |

## Ручная приёмка перед сдачей

- Записать голосовой ответ, сбросить запись клавишей Escape и отправить клавишей Enter
- Пройти текстовый ввод: Enter отправляет ответ, Shift+Enter создаёт новую строку
- Проверить отказ в доступе к микрофону, сетевую ошибку, сброс и повторную отправку
- Проверить анимацию изменения фрагмента текста, режим уменьшения движения и мобильную ширину
- Проверить копирование, PDF и опубликованный HTTPS-адрес после развёртывания

Автоматический доступ к браузеру в рабочей среде недоступен. Поэтому результаты визуальной проверки и живого микрофона не заменяются техническими тестами.
